# Centro Óptico de Colombia Group

Aplicación web para la gestión de pacientes, jornadas visuales, agenda, Call Center, brigadas, consultas, ventas, recaudos, reportes, usuarios y permisos.

## Publicación

Proyecto web estático conectado a Supabase. Puede publicarse directamente desde la raíz del repositorio en Netlify.

## Seguridad

El frontend utiliza únicamente la clave publicable de Supabase. Nunca debe incluirse una clave `service_role` o secreta.
